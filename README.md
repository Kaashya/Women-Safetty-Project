# Women Safety Analytics — CCTV Safety Monitoring Prototype

An AI-powered CCTV safety monitoring prototype designed to process surveillance video streams, detect and track people, identify potential safety events (such as possible falls), and provide a human verification dashboard.

> **IMPORTANT DISCLAIMER**  
> Alerts generated by this system represent **potential safety events** (e.g., a possible fall or distress posture) and **NOT confirmed crimes or definitive emergencies**. All alerts require human operator verification before any operational or dispatch action is taken.

## 3. Installation & Setup

### Prerequisites
- Python 3.8 to 3.11 installed.

### Step 1: Clone the Repository
```bash
git clone <repository_url>
cd women-safety-analytics
```

### Step 2: Create and Activate Virtual Environment

**On Windows:**
```powershell
python -m venv .venv
.venv\Scripts\activate
```

**On Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Step 3: Install Dependencies
```bash
pip install -r requirements.txt
```

> **Note**: `requirements.txt` contains only packages strictly required for Member 1 (`ultralytics`, `opencv-python`, `numpy`, `lap`). Member 2 and Member 3 can install their additional dependencies (`mediapipe`, `streamlit`) when developing their modules.

## 5. Running Member 1 (CLI Demonstration)

The CLI entry point is `main.py`.

### A. Run Interactive Detection on a Video
Opens an OpenCV window with bounding boxes, tracking IDs, and confidence scores:
```bash
python main.py --video data/normal/walking_01.mp4
```
*Controls:* Press `q` or `ESC` in the playback window to exit.

### B. Run Detection and Save Annotated Output Video
Processes the video and saves an annotated `.mp4` into `outputs/`:
```bash
python main.py --video data/normal/walking_01.mp4 --save
```
*(Optional)* Specify a custom output path:
```bash
python main.py --video data/normal/walking_01.mp4 --save --output outputs/my_result.mp4
```

### C. Run in Headless Mode (No GUI Window)
Useful for automated testing, servers, or batch processing:
```bash
python main.py --video data/fall/fall_01.mp4 --headless
```

### D. Adjust Confidence Threshold or Disable Tracking
```bash
# Higher confidence threshold (e.g. 0.6):
python main.py --video data/normal/walking_01.mp4 --confidence 0.6

# Disable tracking (raw YOLO detection only):
python main.py --video data/normal/walking_01.mp4 --no-track
```

### E. Run on Webcam Input
```bash
python main.py --video 0
```

## 6. Standard Detection Output Contract

For every frame processed, `PersonDetector.detect_frame()` returns a structured dictionary:

```python
{
    "frame_id": 125,                    # int: 1-indexed sequential frame number
    "timestamp": 4.16,                  # float: Elapsed video time in seconds
    "frame": original_frame,            # np.ndarray: Original BGR frame
    "annotated_frame": annotated_frame, # np.ndarray: BGR frame with bounding boxes and labels
    "people": [
        {
            "track_id": 1,              # int or None: Persistent tracking ID across frames
            "bbox": [120, 80, 240, 360],# list: Clamped pixel coordinates [x1, y1, x2, y2]
            "confidence": 0.91          # float: Detection confidence score (0.0 to 1.0)
        },
        {
            "track_id": 2,
            "bbox": [310, 95, 420, 380],
            "confidence": 0.87
        }
    ]
}
```

## 8. Integration Guide for Member 3 (Streamlit Dashboard & SQLite)

Member 1's detection module is strictly headless and **never calls `cv2.imshow()`**. Member 3 can import `PersonDetector` directly into a Streamlit script without GUI conflicts:

```python
import streamlit as st
import cv2
from src.detection import PersonDetector

st.set_page_config(page_title="Women Safety Analytics", layout="wide")
st.title("AI CCTV Safety Monitoring")

video_path = "data/normal/walking_01.mp4"
detector = PersonDetector(confidence=0.4, track=True)

video_placeholder = st.empty()
info_placeholder = st.sidebar.empty()

for frame_data in detector.process_video(video_path):
    frame_id = frame_data["frame_id"]
    timestamp = frame_data["timestamp"]
    annotated_frame = frame_data["annotated_frame"]
    people = frame_data["people"]

    # Streamlit requires RGB image
    rgb_frame = cv2.cvtColor(annotated_frame, cv2.COLOR_BGR2RGB)
    video_placeholder.image(rgb_frame, channels="RGB", use_container_width=True)

    info_placeholder.markdown(f"**Frame:** {frame_id} | **Time:** {timestamp:.2f}s | **People:** {len(people)}")

    # MEMBER 3 WORKFLOW:
    # 1. Interleave Member 2's event detector.
    # 2. Render active alerts in a sidebar or table with 'Verify' and 'Dismiss' buttons.
    # 3. Write alerts and verification actions to SQLite.
```

## 10. Privacy, Ethics & Responsible AI

1. **Generic Person Detection Only**:
   - The model is restricted to generic person detection (`classes=[0]` in COCO).
   - **No facial recognition**, gender classification, age estimation, or demographic profiling is implemented.
2. **Temporary Session-Level IDs**:
   - Tracking IDs (`Person 1`, `Person 2`) are short-lived video sequence counters. They do not represent real-world identities.
3. **Probabilistic Triage & Human Verification**:
   - System outputs are framed as **"Potential Safety Events"** or **"Possible Falls"**.
   - Alerts are flagged as `pending` until reviewed and confirmed or dismissed by a human operator.

## 11. Known Limitations

- **Occlusion & ID Switches**: Fast motion or prolonged overlap between multiple people may cause tracking IDs to reset or switch.
- **Low Resolution & Distant Cameras**: Surveillance cameras mounted far away may reduce YOLO detection recall on small targets.
- **Lighting Conditions**: Severe underexposure or lens glare can impact detection confidence.
- **Fall Detection Scope**: Fall detection is not yet implemented (scheduled for Member 2).
